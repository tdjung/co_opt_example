부록 — 요구사항 분석: 기존 수단과의 비교

초 단위 루프에 필요한 것 다섯 가지, 기존 수단은 하나씩 빠져 있습니다

필요한 것RTL 시뮬FPGA · 에뮬레이터기능(LT) 시뮬이 과제
R1 · SW를 개발할 수 있는 속도✕ 수 KIPS○○○ 50배+ vs RTL
R2 · cycle 수준 정확도○○✕ 타이밍 없음○ 99.7%
R3 · 원인을 보여주는 분석 데이터△ 파형뿐△ 프로브·재합성 필요△○ callgrind + 파형
R4 · HW 구조를 바꿔 볼 수 있음✕ RTL 재작성✕ 재합성 수 시간△○ config 한 줄
R5 · 반복을 사람 대신 돌릴 수 있음–––○ AI 루프 + 사람 검토

R1~R4를 한 플랫폼이 동시에 만족해야 R5(자동 최적화 루프)가 가능합니다. FPGA·에뮬레이터는 대체 대상이 아니라 루프 결과의 검증 수단(WaveScope). 공개 도구 참고: gem5는 Cortex-M 미지원, GVSoC는 RISC-V 전용, Arm Fast Model은 기능 수준(LT).

Q&A 대비용. "왜 기존 도구로 안 되나", "왜 gem5 안 썼나"가 오면 이 장을 띄운다.
